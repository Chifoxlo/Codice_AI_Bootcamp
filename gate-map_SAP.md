## SAP Transport Request (TR) Promotion (Migration from Dev to QA/Prod)

| | Specify | Implement | Verify | Release | Operate |
|---|---|---|---|---|---|
| **Gates (D/M/H)** | **H**: Functional & Business Analyst sign-off on Functional/Technical Specifications (FSD/TSD). <br><br>**D**: ChaRM/SolMan automatic mapping of TR to Change Document. | **D**: ABAP Test Cockpit (ATC) syntax, security, & performance checks. <br><br>**M**: GenAI Code Review Agent (validates compliance with custom SAP naming conventions & runbooks). | **D**: Automated Regression Test Suite (e.g., via Tricentis Tosca or SAP CBTA). <br><br>**H**: Key Business User Acceptance Testing (UAT) sign-off in the QA environment. | **H**: Change Advisory Board (CAB) & Basis Team manual deployment authorization. <br><br>**D**: Automated dependency & sequencing conflict check (pre-import check). | **D**: Automated post-import monitoring (ST22 dumps, SM21 system logs, SM12 lock tables). <br><br>**M**: Log Anomaly Detection Agent alerting on post-migration system performance degradation. |
| **Level + why (rubric)** | **L2 (Assisted Autonomy)** <br>• **Blast Radius**: **High**. A faulty SAP transport can halt core business processes (e.g., shipping, invoicing, or payroll). <br>• **Reversibility**: **Low**. SAP transports are "overwrite" deployments; there is no native, single-click "rollback." Reverting requires importing a compensating transport or restoring backups. <br>• **Verification Strength**: **Medium**. While unit and regression testing are robust, complex integration points with external systems make full end-to-end automation difficult. <br>• **Sensitivity**: **High**. Touches highly sensitive enterprise financial and customer databases. <br><br>*Because of the high blast radius, low reversibility, and manual nature of UAT, the release gate must remain human-controlled (CAB/Basis).* | | | | |
| **Promote to L3 when** | • **Robust Automated Verification**: The automated regression test suite achieves >90% test coverage of critical business processes with zero manual interventions required over 30 consecutive QA deployments. <br>• **Virtual Import Checks**: Deployment tools guarantee 100% automated detection of sequence errors, missing object dependencies, and overwrite conflicts prior to import. | | | | |
| **Demote to L1 when** | • **Production Incident**: Any production downtime, P1/P2 incident, or data inconsistency is caused by a promoted transport. <br>• **Stale Test Automation**: The failure/flake rate of automated regression scripts in QA exceeds 5%, indicating the automation is no longer a reliable gatekeeper. <br>• **Security Bypass**: Any unauthorized data exposure or security compliance violation bypasses the automated ATC checks. | | | | |
